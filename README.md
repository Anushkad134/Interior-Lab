# Interior-Lab


**AI-Powered Interior Design & Room Redesign Studio**

Built by [Anushka Dabhade](https://www.linkedin.com/in/anushka-dabhade-936b16349/) as part of the [TechTrinetra7](https://www.linkedin.com/company/techtrinetra7/) AI/ML Skill Sprint — Project Showcase, Phase 1.

InteriorIQ AI Studio is an end-to-end AI application that turns a single uploaded room photo into a budget-aware redesign concept, combining computer vision, classical machine learning, large language models, and multimodal AI in one pipeline.

---

## Problem Statement

Redesigning a room means answering several questions at once:

- What furniture should be kept?
- What should be replaced?
- Which colours will work together?
- How can the redesign fit within a specific budget?

InteriorIQ AI Studio analyses what's actually present in a room and generates a personalised redesign plan based on budget, preferred style, and colour preferences.

| Layer | Technology |
|---|---|
